# Express & Socket.IO Real-Time Chat Server

A real-time communication server built using **Express** and **Socket.IO**.

## Features
- ✅ Create Room
- ✅ Join Room
- ✅ Leave Room
- 💬 Two-way chat between clients

## Setup
1. Install dependencies:
   ```bash
   npm install express socket.io

2. Start Serer
    ```bash
    node index.js

3. Kill Port if needed
    ```bash
    kill -9 $(lsof -t -i tcp:3001)

4. Open two browser tabs:
    http://localhost:3001/
